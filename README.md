# Unit-9

# Prerequisities
Install python version 3.x (for example using Anaconda)

# Setup
some instructions here

1. Clone []
2. Navigate tot he local repo from the command line
3. Make sure the Anaconda base environment is active
"rps-env" (first time only):

```sh
conda create -n rps-env python=3.11
```

4. Activat the virtual environment as necessary (every
time you come back to the project):

```sh
conda activate rps-env
```

5. Install package dependencies
# Usage

Run the example script:

```sh
python3 app/my_script.py
python3 app/rps.py
```

# alternatively:
python3 -m app.my_script

python3 -m app.rps
```
